# Концепция Yazi2D

## 1. Цель

Сделать быстрый терминальный файловый менеджер, который соединяет:

- **скорость, лаконичность и эстетику Yazi**;
- **понятную двухпанельную модель Total Commander**;
- минимум лишнего: пользователь сразу видит два каталога, путь к каждому,
  избранное и умеет копировать/перемещать файлы между панелями.

Yazi2D — не попытка повторить весь Yazi. Это самостоятельный продукт с
ограниченным, но доведённым до удобства набором возможностей.

## 2. Пользователь и сценарии

**Пользователь:** разработчик, администратор, power-user терминала, который
часто раскладывает файлы между каталогами и дисками.

Основные сценарии:

1. «Скопируй выбранные файлы из `~/Projects` в `/Volumes/Backup`».
2. «Перекинь папку из левой панели в правую, не потеряв выделение».
3. «Сохрани текущий каталог в избранное и вернись к нему завтра».
4. «Быстро создай папку, переименуй файл, удали мусор».
5. «Перейди на уровень выше и останься курсором на той папке, откуда вышел».

## 3. Продуктовые принципы

1. **Две панели — основа.** Любая операция копирования/перемещения направлена
   в другую панель. Никаких промежуточных диалогов выбора назначения.
2. **Путь всегда перед глазами.** Первая строка внутри каждой панели — текущий
   абсолютный путь. Длинный путь обрезается слева, хвост сохраняется.
3. **Избранное — рядом.** Боковая панель закладок видна по умолчанию; текущий
   каталог добавляется одной клавишей и сохраняется между запусками.
4. **Ничего не теряется.** Существующие файлы не перезаписываются: при
   конфликте добавляется суффикс ` (1)`, ` (2)` и т.д.
5. **Быстро и отзывчиво.** Файловые операции — в фоне; UI не замирает; простой
   экран не перерисовывается без изменений.
6. **Клавиатура прежде всего.** Мышь не требуется. У F-клавиш есть буквенные
   дубликаты (важно для macOS, где F-клавиши часто заняты системой).
7. **Предсказуемость.** `..` — это строка навигации, а не объект операций.
   Выделение отменяется при смене каталога. Перемещение в тот же каталог
   запрещено.

## 4. Границы MVP

Входит:

- две независимые панели;
- строка пути в каждой панели;
- избранное с сохранением в TOML;
- копирование и перемещение между панелями (файлы, каталоги, симлинки);
- создание каталога, переименование, удаление с подтверждением;
- множественное выделение;
- показ/скрытие скрытых файлов;
- сортировка «каталоги сначала», затем по имени без учёта регистра;
- фоновый прогресс операций;
- справка и статусная строка.

Не входит (см. `ROADMAP.md`):

- просмотр/редактирование файлов;
- поиск и фильтрация;
- архивы, SSH/SFTP, корзина;
- мышь, темы, настраиваемые раскладки;
- вкладки, превью изображений, плагины;
- полноценный диалог конфликтов «заменить/пропустить/переименовать».

## 5. Экран

```
┌ Favorites ─────────────┐┌ Left ──────────────────────┐┌ Right ─────────────────────┐
│ ● Дом                  ││ /Users/me/Projects         ││ /Volumes/Backup            │
│   Загрузки             ││   Name              Size   ││   Name              Size   │
│   Документы            ││ ▸ src/                     ││ ▸ 2026/                    │
│                        ││   README.md         8.1K   ││   notes.md          12.4K   │
└ Ctrl+B add ────────────┘└────────────────────────────┘└────────────────────────────┘
 Copied 3 item(s).                                  README.md  file  2026-11-11 09:41
 Yazi2D · Tab switch · F5/c copy · F6/m move · F7/n mkdir · F8/d delete · F2/r rename · ...
```

Слои:

1. **Тело**: избранное (26 колонок) + левая панель + правая панель.
   При ширине < 72 избранное временно скрывается, панели делят экран.
2. **Статусная строка**: сообщение/выделение слева, прогресс операции или
   информация о текущем элементе справа.
3. **Футер**: контекстная подсказка по клавишам.
4. **Оверлеи**: ввод имени, подтверждение удаления, справка.

Панель:

- рамка с названием `Left`/`Right`, активная — голубая;
- строка пути (первая внутренняя строка, синий фон);
- заголовок колонок `Name / Size / Modified` (при достаточной ширине);
- список: `▸` каталог, `▣` выбранный, `↑` родительский каталог, `@` симлинк.

## 6. Клавиатурная модель

| Контекст | Клавиши |
|---|---|
| Панели | `Tab`, стрелки/`hjkl`, `PgUp/PgDn`, `Home/g`, `End/G`, `Enter/l`, `Backspace/h`, `Space/Insert`, `Esc` |
| Операции | `F5/c`, `F6/m`, `F7/n`, `F2/r`, `F8/d/Del` |
| Избранное | `Ctrl+F/f`, `Ctrl+B/a`; внутри: стрелки, `Enter`, `Del/d`, `Esc` |
| Прочее | `Ctrl+R`, `.`, `?/F1`, `q/Ctrl+C` |

Полная таблица — в `README.md` и во встроенной справке (`?`).

## 7. Файловые операции

### Копирование (`F5` / `c`)

- Источник: выделенные элементы в активной панели; если выделения нет —
  элемент под курсором.
- Назначение: текущий каталог другой панели.
- Каталоги копируются рекурсивно, симлинки пересоздаются как симлинки.
- Конфликт имён → новое имя с суффиксом ` (1)`, расширение сохраняется.
- Копирование каталога внутрь самого себя запрещено.

### Перемещение (`F6` / `m`)

- Та же модель источника/назначения.
- В пределах одной ФС используется атомарный `rename` (мгновенно).
- При переходе между ФС — копирование с последующим удалением источника.
- Перемещение в родительский каталог источника запрещено (это был бы no-op).

### Удаление (`F8` / `d` / `Del`)

- Сначала диалог `Delete N item(s)? (y/N)`.
- Удаление каталогов рекурсивное, без корзины (MVP).
- Симлинк удаляется как ссылка, а не как цель.

### Создание и переименование

- Имя не может быть пустым, содержать `/`, быть `.` или `..`.
- Переименование не перемещает файл в другой каталог.
- После успешной операции обе панели обновляются, курсор встаёт на результат.

## 8. Производительность

- Один UI-поток; ввод обрабатывается каждые 80 мс.
- Тяжёлые операции — в отдельном потоке, прогресс через `mpsc`.
- Перерисовка только при `dirty` (ввод, прогресс, resize).
- Список каталога читается синхронно (как в MVP); для очень больших каталогов
  следующим шагом будет фоновая загрузка/виртуализация.
- Release-сборка с LTO; бинарник около 1 МБ.

## 9. Хранение данных

Единственный persistent state MVP — избранное:

```
$YAZI2D_CONFIG_DIR/favorites.toml
~/.config/yazi2d/favorites.toml            # Linux
~/Library/Application Support/yazi2d/...   # macOS
```

Формат — простой TOML-массив абсолютных путей. При первом запуске добавляются
существующие `~`, `Desktop`, `Documents`, `Downloads`.

## 10. Критерии готовности MVP

- [x] Две панели отображаются одновременно и независимо навигируются.
- [x] В каждой панели виден текущий путь.
- [x] Избранное добавляется, сохраняется, переживает перезапуск, навигируется.
- [x] Копирование и перемещение между панелями работают для файлов и каталогов.
- [x] Ошибки не роняют приложение и видны в статусной строке.
- [x] Юнит-тесты и PTY-тест зелёные.
- [x] `fmt`, `clippy -D warnings`, release-сборка проходят.
