# План развития Yazi2D

Статусы: `[x]` сделано, `[ ]` не сделано. Порядок внутри этапов — приоритет.

## Этап 0. Фундамент — готово

- [x] Выбрать самостоятельную кодовую базу на Rust + ratatui (ADR-001).
- [x] Каркас: событийный цикл, raw mode, восстановление терминала, panic hook.
- [x] Модель панели, чтение каталога, сортировка, курсор, выделение.
- [x] Документация для передачи: `AGENTS.md`, `docs/`.

## Этап 1. MVP — готово (`0.1.0`)

- [x] Две независимые панели.
- [x] Строка текущего пути в каждой панели.
- [x] Избранное: боковая панель, добавление, переход, удаление, TOML.
- [x] Копирование между панелями (файлы, каталоги, симлинки).
- [x] Перемещение между панелями, fast-path через `rename`.
- [x] Фоновые операции + прогресс в статусной строке.
- [x] Создание каталога, переименование, удаление с подтверждением.
- [x] Мультивыделение, скрытые файлы, обновление.
- [x] Защита от перезаписи: суффикс ` (1)`.
- [x] Справка, футер, статус.
- [x] Юнит-тесты (14) + PTY end-to-end тест.
- [x] fmt / clippy `-D warnings` / release build.

## Этап 1.6. Диагностика, отзывчивость и macOS — готово (`0.3.0`)

## Этап 2. Полировка UX — следующий

### 2.1. Конфликты и операции

- [ ] Пользовательские цвета: переназначение отдельных расширений из меню.
- [ ] Клики мышью (фокус панели, выбор строки, колесо по миниатюрам).
- [ ] Предпросмотр массового переименования до применения.
- [ ] Диалог конфликта: `Replace / Skip / Rename / Apply to all`.
- [ ] Отмена текущей операции (`Esc`), безопасная остановка между файлами.
- [ ] Прогресс в байтах и ETA (сейчас — количество объектов).
- [ ] Сохранять выделение после копирования/перемещения.
- [ ] Очередь операций вместо запрета второго задания.
- [ ] Подтверждение перезаписи при перемещении с заменой (после диалога).

### 2.2. Навигация и поиск

- [ ] Быстрый фильтр по текущему каталогу (`/` или `Ctrl+F` внутри панели).
- [ ] Режимы сортировки: имя / размер / дата / расширение, реверс.
- [ ] Переход по пути вводом (`Ctrl+L`).
- [ ] История каталогов назад/вперёд (нужны новые клавиши: `Alt+←/→` заняты
      открытием папки в соседней панели, см. ADR-013/ADR-017).
- [ ] Прыжок к началу/концу списка с учётом больших каталогов.
- [ ] Виртуализация очень больших каталогов (сейчас загрузка уже фоновая, но
      список целиком живёт в памяти).

### 2.3. Просмотр и редактирование

- [x] `Ctrl+Q` / `Ctrl+←/→` — быстрый просмотр текста, изображений, каталогов.
- [x] `Ctrl+T` — режим миниатюр.
- [ ] `F4` — открыть файл во внешнем `$EDITOR`.
- [ ] Полноэкранный просмотрщик (`F3`) с собственным окном и поиском.
- [ ] Показ размера каталога по запросу (не в основном цикле).
- [ ] Копировать путь/имя в буфер обмена (`Ctrl+Shift+C` с fallback).

### 2.4. Комфорт

- [ ] Мышь: клик по строке, двойной клик — вход, колесо — прокрутка.
- [ ] Настраиваемые клавиши и тема через `config.toml`.
- [ ] Скрывать/показывать колонки в зависимости от ширины (сейчас авто).
- [ ] Индикатор свободного места на диске в статусе.
- [ ] Человекопонятные сообщения об ошибках + файл лога.
- [ ] Поддержка `~` и относительных путей в CLI и избранном.

### 2.5. Безопасность данных

- [ ] Удаление в корзину (macOS Trash / freedesktop) с fallback.
- [ ] Подтверждение для рекурсивного удаления больших каталогов.
- [ ] Проверка прав и частичных ошибок с итоговым отчётом.
