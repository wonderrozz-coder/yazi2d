# Статус проекта

**Дата:** 2026-11-11
**Версия:** `0.3.2` (диагностика, отзывчивость, macOS-клавиши, качество картинок)
**Состояние:** работоспособный двухпанельный файловый менеджер с быстрым
просмотром текста/изображений/каталогов, режимом миниатюр, фоновой загрузкой
каталогов и файловым логом.

## Что готово

- Две панели (`Left`/`Right`) с независимыми cwd, курсором, скроллом и выделением.
- Строка текущего пути в верхней части каждой панели.
- Избранное: боковая панель, вход по `Shift+Tab`, двойному `Tab` (и `Ctrl+D`), добавление
  текущего каталога, переход, удаление, сохранение в TOML и загрузка при старте.
- Копирование (`F5`/`c`) и перемещение (`F6`/`m`) между панелями:
  - файлы, каталоги рекурсивно, симлинки;
  - перемещение через `rename` на одной ФС, иначе copy+remove;
  - защита от копирования каталога в себя и перемещения в тот же родительский каталог;
  - уникальные имена при конфликте (`name (1).ext`).
- Фоновые операции с прогрессом; UI остаётся отзывчивым.
- `F7`/`n` — создать каталог, `F2`/`r` — переименовать,
  `F8`/`d`/`Del` — удалить; подтверждение по `Enter` (или `y`).
- Мультивыделение (`Space`/`Insert`), выделить всё (`Ctrl+A`), скрытые файлы
  (`Ctrl+H` или `.`), обновление (`Ctrl+R`).
- Сортировка (`s` или `Ctrl+S`): имя / размер / тип / дата, с реверсом (`r`).
  `..` всегда первая строка, каталоги идут перед файлами.
- Массовое переименование (`Ctrl+G`) по шаблону: `{name}`, `{ext}`, `{n}`,
  либо `%e=txt` для смены только расширения.
- Цвета по типам файлов (`Ctrl+K`): папки, изображения, видео, аудио, текст,
  архивы, временные, 3D-модели, код, прочее. Три темы: default / vivid / mono,
  выбор сохраняется в `$YAZI2D_CONFIG_DIR/theme`.
- Режимы панели: `List`, `Thumbnails`, `Preview`.
- Быстрый просмотр:
  - текст до 512 КБ (до 5000 строк), табы раскрываются;
  - двоичные файлы — hex-дамп;
  - изображения PNG/JPEG/GIF/WebP/BMP/TIFF рисуются half-блоками в truecolor;
  - **каталоги — сетка миниатюр** (как в режиме `Ctrl+T`), файлы превью как раньше;
  - `Ctrl+Q`/`Ctrl+P` всегда открывают просмотр в **противоположной** панели;
  - просмотр следует за курсором активной панели, только один просмотрщик;
  - прокрутка `↑↓`/`PgUp/PgDn`/`Home/End` и `←→`/`h`/`l`;
  - закрытие `Esc`, `Ctrl+Q`/`Ctrl+P` или повторным `Ctrl+←/→`; только для чтения.
- `Ctrl+←/→` — просмотр в указанной панели (алиас), `Alt+←/→` и `Ctrl+O` —
  открыть папку под курсором в соседней панели.
- `Ctrl+T` — сетка миниатюр с кэшем декодированных изображений; размер плиток
  адаптивный, ресайз — Lanczos3 после ограничения исходника до 1600 px.
- **Фоновая загрузка каталогов**: вход/выход/обновление не блокируют UI,
  панель показывает `Loading <path>…`, `Esc` отменяет загрузку.
- **Листинг без `stat`**: имена и типы берутся из самого `read_dir`, а размеры и
  даты дозаполняются фоновым воркером. Это устранило 13-секундные зависания на
  облачных папках Nextcloud.
- **Асинхронные превью и изображения**: чтение каталога, текста и декодирование
  картинок идут в фоновых потоках, поэтому UI больше не замирает.
- **Файловый лог** `yazi2d.log`: старт, каждая загрузка каталога с временем,
  медленные загрузки как `WARN`, декодирование изображений, задания, паника.
  Строки пишутся и сбрасываются сразу, чтобы последняя строка пережила зависание.
- **Трекпад**: два пальца вверх/вниз листают список (инвертировано, «тянем
  содержимое»); влево/вправо работают как `←`/`→` в текущем режиме.
- **Живой футер**: при зажатом `Ctrl`/`Alt`/`Shift` нижняя строка показывает
  только сочетания с этой клавишей (нужен kitty keyboard protocol).
- Справка (`?`/`F1`), статусная строка, контекстный футер.
- Отрисовка только при изменениях (`dirty`), простой экран не грузит CPU.

## Проверки

Все проверки проходят на macOS 15.6.1 (Apple Silicon), Rust 1.99.1:

```
cargo fmt --check                                  OK
cargo clippy --all-targets -- -D warnings          OK
cargo test --all-targets                           52 passed
python3 scripts/e2e_pty.py target/debug/yazi2d     E2E OK
cargo build --release                              OK, бинарник ~2 MB
```

PTY-тест проверяет: обе панели и избранное, копирование и перемещение файлов,
скрытые файлы по `Ctrl+H`, быстрый просмотр по `Ctrl+P`, миниатюры по `Ctrl+T`,
фокус избранного по `Shift+Tab`, выделение всего по `Ctrl+A`, меню сортировки,
меню цветов по `Ctrl+K`, справку, создание каталога, удаление по `Enter`,
открытие папки в соседней панели по `Ctrl+O` и корректный выход по `q`.

## Известные ограничения

1. **Нет диалога конфликтов** — существующие имена не перезаписываются, а
   получают суффикс. Выбрать «заменить/пропустить» нельзя.
2. **Нет отмены операции** — фоновая задача всегда доводится до конца.
3. **Удаление безвозвратное**, без корзины.
4. **Изображения рисуются half-блоками** — без sixel/Kitty/iTerm2-протоколов;
   качество зависит от терминала, шрифта и размера панели. Lanczos3 и
   адаптивные плитки заметно улучшают картинку, но не добавляют физических
   пикселей.
5. **Просмотр только для чтения** — редактирования и внешнего `$EDITOR` нет.
6. **Декодирование изображений идёт в фоне**, но ограничено четырьмя
   одновременными задачами и лимитом 64 МБ на файл; очень большие TIFF могут
   занимать память.
7. **Одна операция за раз** — второе задание отклоняется сообщением.
8. **Нет мыши, тем, настраиваемых клавиш.**
9. **Ошибки операции** показываются только первой строкой в статусе; полный
   список хранится в `Job::errors` до завершения.
10. **macOS:** F-клавиши могут требовать `Fn`; `Ctrl+←/→` и `Alt+←/→` могут
    перехватываться системой/терминалом. Используйте `Ctrl+P`, `Ctrl+O`,
    `Ctrl+T`, `Shift+Tab` — альтернативы без стрелок.
11. **Эмодзи/ZWJ** в именах могут немного смещать колонки (учтена обычная
    Unicode-ширина, но не все кластеры).
12. **`Alt+←/→` больше не история** — эти клавиши заняты открытием папки в
    соседней панели (осознанное решение, см. ADR-013/ADR-017).
13. **Первоначальная загрузка каталогов синхронная** (вместе с размерами) и
    может задержать запуск на медленной файловой системе.
14. **Нет пользовательских цветов** — только три готовые темы; отдельные
    расширения нельзя переназначить из UI.
15. **Массовое переименование без предпросмотра** — шаблон применяется сразу,
    конфликты пропускаются с сообщением в статусе.

## Ближайшие задачи (следующие 3)

1. **Диалог конфликтов** при копировании/перемещении:
   `Replace / Skip / Rename / Apply to all`, интеграция с фоновым job-протоколом.
2. **Отмена операции**: `Arc<AtomicBool>` в `Job`, проверка между файлами,
   сообщение `Cancelled`, корректный статус.
3. **Быстрый фильтр и сортировка**: фильтр по подстроке в текущем каталоге,
   режимы имя/размер/дата/расширение и реверс.

После них — полноэкранный `F3`, прогресс в байтах, корзина, мышь.

## Логи и диагностика

Лог включён по умолчанию и пишется в:

```
$YAZI2D_CONFIG_DIR/yazi2d.log                       # если переменная задана
~/.config/yazi2d/yazi2d.log                         # Linux
~/Library/Application Support/yazi2d/yazi2d.log     # macOS
```

Управление:

```sh
YAZI2D_LOG=off yazi2d                    # выключить
YAZI2D_LOG=/tmp/yazi2d.log yazi2d        # свой путь
tail -f ~/Library/Application\ Support/yazi2d/yazi2d.log
```

Что искать при зависании: строки `WARN slow directory load` с путём и временем,
а также последнюю строку `INFO load start` — она называет каталог, на котором
приложение застряло. При запуске лог больше 4 МБ ротируется в `yazi2d.log.1`.
Запись асинхронная, при переполнении очереди сообщения могут теряться.

## Как продолжить с любого места

```sh
# 1. Поставить Rust, если его нет
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --profile minimal
source "$HOME/.cargo/env"

# 2. Собрать и запустить
cargo run --release

# 3. Прогнать проверки
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test --all-targets
cargo build --release
python3 scripts/e2e_pty.py target/debug/yazi2d
```

Если проект в синхронизируемой папке:

```sh
export CARGO_TARGET_DIR="$HOME/.cache/yazi2d-target"
```
