# Статус проекта

**Дата:** 2026-11-12
**Версия:** `0.6.6` (одно «open there», F9 удалён, подсказка про разделитель)
**Состояние:** работоспособный двухпанельный файловый менеджер с быстрым
просмотром текста/изображений/каталогов, режимом миниатюр, фоновой загрузкой
каталогов, файловым логом, мышью, рекурсивным поиском и сборками под Windows.

## Что нового в `0.6.6`

- **Одно действие «open there»** вместо трёх: `Ctrl+O` и `Shift+→` — два слота
  одного действия, `Shift+←` — зеркало той же привязки. Отдельного
  `OpenFolderThere` больше нет.
- **F9-лидер удалён целиком** (состояние, подсказка в статусе, плашка в футере,
  строка в `F1`, `--help`). `F9` стал обычной свободной клавишей.
- **`S` в панелях объясняет себя**: вместо молчаливого ничего — подсказка
  «press § or Ctrl+D, then S». Сам разделитель в избранном работает.

## Что нового в `0.6.5`

- **Избранное — это список типизированных строк**: путь (папка **или файл**) и
  именованный разделитель. Старый плоский `favorites = [...]` продолжает
  читаться.
- **`↑↓` листают и показывают** строку в активной панели, не выходя из списка:
  папка открывается, файл показывается в превью. **`Enter`/`→`** переходят.
- **`PageUp/PageDown`** переставляют строку и сразу сохраняют порядок.
- **`S`** добавляет разделитель с названием.
- **`Ctrl+B`** добавляет в избранное элемент под курсором, а не только каталог;
  файлы тоже можно бронировать.
- Иконки типов и в панели избранного.
- Контекстное меню: «Open» и «Open folder in the other panel» больше не
  называются одинаково, добавлен «Add to favorites» для элементов и
  «Add a separator».

## Что нового в `0.6.4`

- **Удаление — в корзину**: `Del`/`F8` перемещают в системную корзину
  (freedesktop в Linux с `.trashinfo`, `~/.Trash` на macOS, настоящая корзина в
  Windows). `Shift+Del` — безвозвратное удаление, и подтверждение об этом
  предупреждает. Если корзина недоступна, операция сообщает об ошибке, а не
  стирает молча.
- **Фокус владеет клавишами**: в избранном `Del` удаляет закладку, `Enter`
  открывает её, стрелки двигают курсор — файловые операции туда больше не
  пробиваются. Именно из-за этого был удалён реальный каталог.
- **`Shift+→` больше не срабатывает на простую `→`**: модификаторы сравниваются
  точно, Shift перестал «протекать» в привязки без Shift.

## Что нового в `0.6.3`

- **Два слота на каждое действие**, оба назначаются в меню `Ctrl+E`
  (`←→` — слот, `Enter` — назначить, `Del` — очистить).
- **Единый источник привязок**: диспетчер, футер и `F1` читают один и тот же
  разрешённый список, поэтому переназначенная клавиша больше не срабатывает
  по-старому (раньше `q` продолжал выходить после переноса выхода на `Ctrl+Q`).
- Переназначаемыми стали все действия, включая выход и `F9`; незыблемы только
  `F1` и первый слот «Settings menu».
- Футер показывает по одной плашке на действие со всеми его клавишами
  (`F5/C copy`) — больше нет трёх «copy» и трёх «delete».
- `F1` генерируется из живых привязок; недокументированный `F9 + ↑/↓` удалён.
- Избранное не закрывается по `Esc` — только своей клавишей.
- `→`/`l` входят в каталог, но больше не открывают файл во внешней программе:
  для файлов только `Enter`.

## Что нового в `0.6.2`

- Колонка `Ext` у папки показывает число вложенных папок первого уровня
  (считается в фоновом воркере, без `stat`).
- `Space` на папке запускает подсчёт её объёма в фоне; результат появляется в
  колонке `Dir` в К/М/Г и дублируется в статусной строке. Кэш по пути, поэтому
  число переживает перезагрузку каталога.
- Футер реагирует на **реальное зажатие** модификатора: включён
  `REPORT_ALL_KEYS_AS_ESCAPE_CODES`, иначе терминал не присылает событий о самих
  модификаторах и экран менялся только после нажатия буквы.

## Что нового в `0.6.1`

- Превью картинок рисуются **протоколом терминала** (kitty в Ghostty, iTerm2,
  sixel): настоящие пиксели вместо полублоков. Протокол определяется по
  окружению, stdin не опрашивается — ввод не блокируется.
  Переопределение: `YAZI2D_IMAGE_PROTOCOL=kitty|iterm2|sixel|halfblocks`.
- **Иконки из темы Yazi**: 713 соответствий (имена каталогов, имена файлов,
  расширения), цвет из темы. `icons = false` возвращает ASCII-маркеры.
- **Ускорение зажатой стрелки**: 55 мс → 12 мс, шаг 1 → 4 строки.
- **Заворот курсора**: у края списка курсор перескакивает на другой край и
  продолжает движение; PgUp/PgDn по-прежнему упираются в край.
- **Футер-плашки**: набор клавиш берётся из реальных привязок, у каждого
  модификатора свой экран (Ctrl/Alt/Shift/Cmd), отпустили — вернулся обычный.

## Что готово

- Две панели (`Left`/`Right`) с независимыми cwd, курсором, скроллом и выделением.
- Строка текущего пути в верхней части каждой панели.
- Избранное: боковая панель, вход по `§`, `Shift+Tab` (и `Ctrl+D`), добавление
  текущего каталога, переход, удаление, сохранение в TOML и загрузка при старте.
- Копирование (`F5`/`c`) и перемещение (`F6`/`m`) между панелями, с
  подтверждением (`Enter`/`y`), как у удаления:
  - файлы, каталоги рекурсивно, симлинки;
  - перемещение через `rename` на одной ФС, иначе copy+remove;
  - защита от копирования каталога в себя и перемещения в тот же родительский каталог;
  - уникальные имена при конфликте (`name (1).ext`).
- Фоновые операции с прогрессом; UI остаётся отзывчивым.
- `F7`/`n` — создать каталог, `F2`/`r` — переименовать,
  `F8`/`d`/`Del` — удалить; подтверждение по `Enter` (или `y`).
- Мультивыделение (`Space`/`Insert`), выделить всё (`Ctrl+A`), скрытые файлы
  (`Ctrl+H` или `.`), обновление (`Ctrl+R`).
- Сортировка (`s` или `Ctrl+S`): имя / размер / тип / дата, с реверсом (`r`).
  `..` всегда первая строка, каталоги идут перед файлами.
- Массовое переименование (`Ctrl+G`) по шаблону: `{name}`, `{ext}`, `{n}`,
  либо `%e=txt` для смены только расширения.
- Цвета по типам файлов (`Ctrl+K`): папки, изображения, видео, аудио, текст,
  архивы, временные, 3D-модели, код, прочее. Три темы: default / vivid / mono,
  выбор сохраняется в `$YAZI2D_CONFIG_DIR/theme`.
- Режимы панели: `List`, `Thumbnails`, `Preview`.
- Быстрый просмотр:
  - текст до 512 КБ (до 5000 строк), табы раскрываются;
  - двоичные файлы — hex-дамп;
  - изображения PNG/JPEG/GIF/WebP/BMP/TIFF рисуются half-блоками в truecolor;
  - **каталоги — сетка миниатюр** (как в режиме `Ctrl+T`), файлы превью как раньше;
  - `Ctrl+Q`/`Ctrl+P` всегда открывают просмотр в **противоположной** панели;
  - просмотр следует за курсором активной панели, только один просмотрщик;
  - прокрутка `↑↓`/`PgUp/PgDn`/`Home/End` и `←→`/`h`/`l`;
  - закрытие `Esc`, `Ctrl+Q`/`Ctrl+P` или повторным `Ctrl+←/→`; только для чтения.
- `Ctrl+←/→` — просмотр в указанной панели (алиас), `Alt+←/→` и `Ctrl+O` —
  открыть папку под курсором в соседней панели.
- `Ctrl+T` — сетка миниатюр с кэшем декодированных изображений; размер плиток
  адаптивный, ресайз — Lanczos3 после ограничения исходника до 1600 px.
- **Фоновая загрузка каталогов**: вход/выход/обновление не блокируют UI,
  панель показывает `Loading <path>…`, `Esc` отменяет загрузку.
- **Листинг без `stat`**: имена и типы берутся из самого `read_dir`, а размеры и
  даты дозаполняются фоновым воркером. Это устранило 13-секундные зависания на
  облачных папках Nextcloud.
- **Асинхронные превью и изображения**: чтение каталога, текста и декодирование
  картинок идут в фоновых потоках, поэтому UI больше не замирает.
- **Файловый лог** `yazi2d.log`: старт, каждая загрузка каталога с временем,
  медленные загрузки как `WARN`, декодирование изображений, задания, паника.
  Строки пишутся и сбрасываются сразу, чтобы последняя строка пережила зависание.
- **Плитки миниатюр**: у каждого типа файла своя крупная блочная иконка
  (папка, картинка, видео, музыка, текст, архив, временный, 3D, код, прочее),
  нарисованная в цвете своей группы; под иконкой — имя и расширение.
- **Колонка `Ext`** в списке: расширение перед размером, не прилипает к имени;
  на узких панелях снова сливается с именем, чтобы не потеряться.
- **Русская раскладка**: горячие клавиши сопоставляются по физической клавише
  (`Ctrl+и` = `Ctrl+B`, `ы` = `s`); в полях ввода кириллица сохраняется.
- **`Enter`** открывает папку, а файл — приложением по умолчанию.
- **Двойной тап** работает и в избранном; принимается нажатие любой кнопки
  мыши, поэтому двухпальцевый тап macOS (правый клик) срабатывает.
- **Меню настроек (`Ctrl+E`)**: переназначение горячих клавиш и переключение
  направления трекпада; сохраняется в `$YAZI2D_CONFIG_DIR/settings.toml`.
- **`F9` + стрелки**: `F9`, затем `←`/`→` — открыть папку под курсором в
  указанной панели, `↑`/`↓` — включить/выключить миниатюры. Работает там, где
  `Ctrl/Alt` + стрелка перехватывается системой.
- **Трекпад**: два пальца вверх/вниз листают список (инвертировано, «тянем
  содержимое»). **Двойной тап двумя пальцами** открывает элемент под курсором:
  папку входит, файл открывает приложением по умолчанию. Горизонтальные
  движения и одиночный тап игнорируются.
- **Живой футер**: при зажатом `Ctrl`, `Option`, `Shift` или `Command` нижняя
  строка показывает только сочетания с этой клавишей (нужен kitty keyboard
  protocol). Список формируется из реально существующих привязок.
- **`Ctrl+F`** показывает и скрывает панель избранного; фокус — `§`/`Shift+Tab`/`Ctrl+D`.
- **Шифт и Alt разведены**: `Shift+←/→` открывает папку под курсором в
  указанной панели, `Alt+←/→` включает там быстрый просмотр. Принимаются и
  «буквенные» `Alt+b`/`Alt+f`, в которые Ghostty/iTerm2 превращают эти стрелки.
  `Ctrl+←/→` — алиас просмотра; `Cmd+←/→` не используются.
- **Футер** сбрасывается на дефолтный, как только приходит клавиша без
  модификаторов, поэтому подсказка не «залипает».
- **`Ctrl+E` нельзя переназначить**, как и `Esc`; меню сообщает об отказе.
- **`Yazi2D.app`** для macOS с иконкой: `packaging/macos/build-app.sh` собирает
  бандл и ставит в `/Applications`. Лаунчер выбирает терминал с truecolor
  (Ghostty → kitty → WezTerm → iTerm2 → Terminal.app), поэтому превью и
  миниатюры не превращаются в чёрные квадраты. Иконка рисуется
  `packaging/render-icon.py` без зависимостей.
- Справка (`?`/`F1`), статусная строка, контекстный футер.
- Отрисовка только при изменениях (`dirty`), простой экран не грузит CPU.

## Проверки

Все проверки проходят на macOS 15.6.1 (Apple Silicon), Rust 1.99.1:

```
cargo fmt --check                                  OK
cargo clippy --all-targets -- -D warnings          OK
cargo test --all-targets                           93 passed
python3 scripts/e2e_pty.py target/debug/yazi2d     E2E OK
cargo build --release                              OK, бинарник ~2 MB
```

PTY-тест проверяет: обе панели и избранное, копирование и перемещение файлов,
скрытые файлы по `Ctrl+H`, быстрый просмотр по `Ctrl+P`, миниатюры по `Ctrl+T`,
фокус избранного по `Shift+Tab`, выделение всего по `Ctrl+A`, меню сортировки,
меню цветов по `Ctrl+K`, справку, создание каталога, удаление по `Enter`,
открытие папки в соседней панели по `Ctrl+O` и корректный выход по `q`.

## Известные ограничения

1. **Нет диалога конфликтов** — существующие имена не перезаписываются, а
   получают суффикс. Выбрать «заменить/пропустить» нельзя.
2. **Нет отмены операции** — фоновая задача всегда доводится до конца.
3. **Удаление безвозвратное**, без корзины.
4. **Изображения рисуются half-блоками** — без sixel/Kitty/iTerm2-протоколов;
   качество зависит от терминала, шрифта и размера панели. Lanczos3 и
   адаптивные плитки заметно улучшают картинку, но не добавляют физических
   пикселей.
5. **Просмотр только для чтения** — редактирования и внешнего `$EDITOR` нет.
6. **Декодирование изображений идёт в фоне**, но ограничено четырьмя
   одновременными задачами и лимитом 64 МБ на файл; очень большие TIFF могут
   занимать память.
7. **Одна операция за раз** — второе задание отклоняется сообщением.
8. **Нет мыши, тем, настраиваемых клавиш.**
9. **Ошибки операции** показываются только первой строкой в статусе; полный
   список хранится в `Job::errors` до завершения.
10. **macOS:** F-клавиши могут требовать `Fn`; `Ctrl+←/→` и `Alt+←/→` могут
    перехватываться системой/терминалом. Используйте `Ctrl+P`, `Ctrl+O`,
    `Ctrl+T`, `Shift+Tab` — альтернативы без стрелок.
11. **Эмодзи/ZWJ** в именах могут немного смещать колонки (учтена обычная
    Unicode-ширина, но не все кластеры).
12. **`Alt+←/→` больше не история** — эти клавиши заняты открытием папки в
    соседней панели (осознанное решение, см. ADR-013/ADR-017).
13. **Первоначальная загрузка каталогов синхронная** (вместе с размерами) и
    может задержать запуск на медленной файловой системе.
14. **Нет пользовательских цветов** — только три готовые темы; отдельные
    расширения нельзя переназначить из UI.
15. **Массовое переименование без предпросмотра** — шаблон применяется сразу,
    конфликты пропускаются с сообщением в статусе.

## Ближайшие задачи (следующие 3)

1. **Диалог конфликтов** при копировании/перемещении:
   `Replace / Skip / Rename / Apply to all`, интеграция с фоновым job-протоколом.
2. **Отмена операции**: `Arc<AtomicBool>` в `Job`, проверка между файлами,
   сообщение `Cancelled`, корректный статус.
3. **Быстрый фильтр и сортировка**: фильтр по подстроке в текущем каталоге,
   режимы имя/размер/дата/расширение и реверс.

После них — полноэкранный `F3`, прогресс в байтах, корзина, мышь.

## Логи и диагностика

Лог включён по умолчанию и пишется в:

```
$YAZI2D_CONFIG_DIR/yazi2d.log                       # если переменная задана
~/.config/yazi2d/yazi2d.log                         # Linux
~/Library/Application Support/yazi2d/yazi2d.log     # macOS
```

Управление:

```sh
YAZI2D_LOG=off yazi2d                    # выключить
YAZI2D_LOG=/tmp/yazi2d.log yazi2d        # свой путь
tail -f ~/Library/Application\ Support/yazi2d/yazi2d.log
```

Что искать при зависании: строки `WARN slow directory load` с путём и временем,
а также последнюю строку `INFO load start` — она называет каталог, на котором
приложение застряло. При запуске лог больше 4 МБ ротируется в `yazi2d.log.1`.
Запись асинхронная, при переполнении очереди сообщения могут теряться.

## Как продолжить с любого места

```sh
# 1. Поставить Rust, если его нет
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --profile minimal
source "$HOME/.cargo/env"

# 2. Собрать и запустить
cargo run --release

# 3. Прогнать проверки
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test --all-targets
cargo build --release
python3 scripts/e2e_pty.py target/debug/yazi2d
```

Если проект в синхронизируемой папке:

```sh
export CARGO_TARGET_DIR="$HOME/.cache/yazi2d-target"
```
